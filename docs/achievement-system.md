# Achievement System

## Scope

- 저장형 업적 상태는 `GameState.achievements`에 기록된다.
- 업적 정의, 추적 힌트, 보상은 `src/data/achievements.ts` 카탈로그를 SSOT로 사용한다.
- 업적 해금 보상 지급 여부는 `AchievementUnlockState.rewardGrantedAt`으로 기록되며, 중복 지급되지 않는다.
- 업적 추적 모드, 현재 추적 대상, 최근 추적 히스토리는 `GameState.achievementTracking`에 기록된다.
- 업적 보상으로 누적되는 메타 특전은 `GameState.achievementPerks`에 기록되며, 현재는 `가방 확장`, `상점 할인`, `특수 진열 해금`을 지원한다.
- 세이브 메타에는 현재 활성 업적 특전 요약이 `achievementPerkSummary`로 함께 저장되어 로비/세이브 UI가 로드 전에도 같은 특전 정보를 표시한다.
- 현재 원정 요약은 `GameState.runSummary`에 기록된다.
- 레거시 세이브는 `migrateLoadedGameState()`에서 업적/추적/런 요약을 자동 정규화하고, 이미 해금된 업적의 누락 보상도 복구한다.

## Integration Points

- 퀘스트 보상 수령
- 시즌 퀘스트 완료 플래그 반영
- 상점 구매 / 여관 휴식
- 이동 시 원정 시작/종료
- 전투 승리 / 보스 정산 / Act 정산
- 세이브 메타데이터 계산

## UI Surface

- 브라우저 로비 `Continue Run` 카드, `업적 기록` 요약, 세이브 슬롯에 업적 해금 수와 다음 업적 목표를 표시하고, 최신 세이브와 추적 슬롯이 다르면 업적 추적 슬롯으로 바로 우회할 수 있다.
- 브라우저 로비 `Continue Run` 카드와 세이브 슬롯은 현재 활성 업적 특전(`Active Perks`)도 함께 표시한다.
- 업적 추적 슬롯으로 불러오면 `Resume Brief`와 `Resume Route`도 업적 추적 맥락으로 표기한다.
- 업적 추적 불러오기는 추적 업적 제목/진행도까지 함께 전달해 로드 직후 브리프 제목과 경로 요약에 반영한다.
- 업적 추적 슬롯이 최신 세이브와 같으면 `Continue Run` 카드 배지와 로드 토스트도 업적 추적 맥락으로 바뀐다.
- 업적 추적 라벨은 `Resume Route` 헤드와 각 작업공간의 `Resume Target` 배지까지 이어진다.
- 같은 라벨은 각 작업공간의 `Resume Note`와 `Resume Action` 레이블에도 이어진다.
- 같은 라벨은 워크스페이스의 `Resume Anchor`, `Resume Command`, `Resume Steps` 스트립에도 이어진다.
- 같은 라벨은 액션 레일의 `Session Plan`, `Next Move`, `Tempo Routes` 계획 표기에도 이어진다.
- 업적 추적 상태면 `Achievements` 작업공간 요약 카드에 현재 추적 대상이 표시되고, 해당 업적 카드는 강조/우선 배치된다.
- 업적 추적 상태면 사이드 `Momentum`과 `Priority Intel`도 현재 추적 업적을 우선 노출하고 같은 라벨을 헤더에 이어받는다.
- 업적 추적 상태면 `Reward Horizon`도 현재 추적 업적을 보상 카드로 앞쪽에 노출하고 같은 라벨을 헤더에 이어받는다.
- 업적 추적 상태면 `Save Control`, `Session Wrap`, `Resume Cue`도 같은 라벨과 추적 대상을 표시해 저장 전후 맥락이 끊기지 않는다.
- 업적 추적 상태면 `Log` 작업공간과 사이드 `Recent Wins`도 추적 업적용 로그 큐와 같은 라벨을 표시한다.
- 업적 추적 상태면 상단 `Live Run` HUD에도 추적 업적 카드와 같은 라벨이 표시된다.
- 업적 추적 대상 작업공간 탭은 `추적 업적` 배지와 바로가기 라우팅을 받는다.
- 업적 추적 대상 작업공간 헤더는 `Achievement Target` 스트립으로 현재 목표와 CTA를 다시 보여 준다.
- 업적 추적 대상 작업공간의 실제 메인 카드도 `업적 목표 카드` 배지와 설명으로 강조된다.
- 업적 타입이 정확히 특정되는 경우, 작업공간 내부 selector도 `업적 목표` 메타를 표시한다.
- 경제 업적은 가능한 경우 특정 상점/아이템까지 포커스가 내려가며 `smart resume`도 같은 타깃을 재사용한다.
- 경제 업적 기반 `Resume Brief`와 `Resume Action`은 상점/아이템명을 직접 보여 줘서 불러오기 직후 확인 대상을 바로 드러낸다.
- 경제 업적 기반 `Next Move`와 세션 플랜도 같은 상점/아이템 확보를 우선 제안해 재개 맥락이 분산되지 않는다.
- 추적 업적 행동을 완료하면 브라우저 `Resume Route`와 토스트가 즉시 다음 임박 업적으로 전환되거나, 후속 목표가 없으면 추적 맥락을 정리한다.
- `Achievements` 작업공간에는 `자동 전환`/`핀 고정` 추적 정책 토글과 최근 추적 히스토리 패널이 있으며, 핀 고정 모드에서는 업적 카드 선택이 현재 추적 대상으로 저장된다.
- 브라우저 업적 카드에는 보상 미리보기가 같이 표시되고, 업적 해금 직후에는 보상 지급 로그가 별도 피드 항목으로 남는다.
- 브라우저/터미널 상점은 업적 특전으로 해금된 할인율과 추가 진열 단계를 실제 판매가와 재고에 반영한다.
- 브라우저 `Achievements` 작업공간은 현재 활성 특전 요약을 함께 보여 주고, `Market` 작업공간은 업적 특전 기반 `상점 할인`과 `해금 진열` 요약을 별도 fact로 노출한다.
- 세이브 메타에는 `trackedAchievement*`, `nextAchievement*`, `achievementTrackingMode`, `achievementTrackingHistory*`를 함께 저장해 브라우저 로비와 터미널 저장 UI가 같은 추적 정보를 공유한다.
- 런 HUD 배지에 현재 해금 수를 표시한다.
- 브라우저 런타임에 `Achievements` 작업공간을 두고 최근 해금과 남은 업적 진행률을 표시한다.
- `Achievements` 작업공간에서 카테고리 필터와 정렬 모드로 미해금/근접 업적을 추적할 수 있다.
- 업적 카드 클릭 시 관련 퀘스트/이동/상점/로그 작업공간으로 바로 점프한다.
- 브라우저 사이드 `Momentum` 패널에 `다음 해금` 카드를 노출해 메인 루프에서도 업적 목표를 추적한다.
- 세이브 불러오기 후 `Resume Cue`와 스마트 재개 브리프는 임박한 업적이 있으면 해당 작업공간을 우선 추천한다.
- 터미널 세이브 슬롯/불러오기 완료/메인 메뉴 최근 기록에도 다음 업적 목표를 함께 표시한다.
- 신규 업적 해금 시 피드에 `업적 해금:` 로그를 남긴다.
- 추적 모드 변경, 수동 핀 고정, 자동 전환, 완료/해제 이벤트도 피드에 `[업적 추적]` 로그를 남긴다.
- 터미널 인게임 메뉴에는 `업적 지휘실`이 추가되어 직접 추적, 모드 변경, 다음 후보 전환, 추적 해제, 최근 추적 기록 확인을 지원한다.
- `업적 지휘실`은 현재 활성 특전(`가방 +칸`, `상점 할인`, `특수 진열`)도 함께 보여 준다.
- 터미널 업적 진행 처리도 퀘스트 정산, 이동, 상점 구매, 전투 정산 직후 보상 로그와 추적 전환 로그를 같이 출력한다.
- 터미널 메인 메뉴에 최근 세이브 기준 업적 진행 요약을 표시한다.
- 터미널 세이브/로드 슬롯과 불러오기 완료 메시지에 업적 진행 수, 추적 모드, 최근 추적 기록을 표시한다.
- 터미널 세이브/로드 슬롯, 불러오기 완료 메시지, 메인 메뉴 최근 기록 요약에도 현재 활성 업적 특전 요약을 표시한다.

## Operations

- 업적 전용 스모크 세트는 `npm run test:achievements:smoke`로 실행한다.
- 이 스모크 세트는 업적 계산, 터미널 메뉴, 상점 특전, 시즌 완료 플래그, 브라우저 런타임, landing/UI 요약, 세이브/메인 메뉴 표면을 함께 검증한다.
